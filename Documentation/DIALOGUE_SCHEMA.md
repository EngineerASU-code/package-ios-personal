# Схема русских реплик

Файл `Shared/Characters/<hero>/dialogue.ru.json` содержит массив записей в UTF-8. ID уникален внутри пакета. При редактуре сохраняйте ID и порядок первых пяти исторических записей `intro`, `pause`, `notice`, `aside`, `spark`. На них ссылаются сохранённые ответы, включая ранние снимки с числовым индексом.

| Поле | Контракт |
|---|---|
| `id`, `text` | Стабильный локальный ключ и самостоятельная русская реплика. Валидатор ограничивает основной текст 90 символами и проверяет нормализованную уникальность во всех пакетах. |
| `category` | Одна из десяти категорий в таблице ниже. |
| `behaviorID`, `action` | ID из behaviors.json и подпись соответствующего действия. |
| `triggers`, `channels`, `requires` | Массивы строк. При выборе должны совпасть триггер и канал, а контекст должен подтвердить все факты из requires. Поддерживаются app, widget и notification. |
| `weight`, `origin` | Целый вес от 1 до 1 000 000 для выбора и редакторская отметка original для включённых текстов. |
| `shortText` | Самостоятельная короткая версия для notification, до 60 символов. |
| `intensity`, `emotions`, `periods` | Дополнительные фильтры уровня общения, настроения и местного периода суток. Утренние и ночные категории имеют ограничения периода по умолчанию. |
| `variables`, `cooldownSeconds` | Дополнительный список обязательных переменных и неотрицательный интервал до повтора. Событийный путь передаёт pendingTasks и completedTasks. В текущем каталоге валидатор требует готовые тексты без фигурных скобок. |

| Категория | На героя | Категория | На героя |
|---|---:|---|---:|
| morning | 10 | day | 10 |
| compliment | 20 | support | 15 |
| tap | 20 | calendar | 20 |
| reminder | 20 | night | 15 |
| return | 8 | rare | 12 |

## Как выбирается строка

- **Контакт.** Индекс по триггеру ограничивает поиск активным пакетом. Ядро проверяет факты, канал, период, настроение, настройки общения и допустимость перехода. Из оставшихся действий выбирает максимальный приоритет, учитывает cooldown и последние 15 выбранных ID героя. Вес реплики умножается на вес действия.
- **Timeline.** Кадр воспроизводим для одного снимка и слота. Для смены реплик применяется детерминированный выбор с весами. Пассивное чтение оставляет историю и отметку утреннего приветствия без изменений.
- **Уведомление.** Планировщик допускает только канал notification и выбирает строку по стабильному ключу слота с учётом настроек. Пользовательские уведомления задач имеют самостоятельный путь планирования.

Если обязательная переменная отсутствует или шаблон оставляет видимые фигурные скобки, запись исключается. Сдержанная интенсивность дополнительно ограничивает длину и выразительность выбранного текста. Отключение комплиментов применяется при выборе реакции и при повторном показе сохранённой строки на поверхности.

Проверку состава пакетов и связей запускают командой `python -B Scripts/validate_content.py`. Детерминированные сценарии находятся в [CompanionTests](../Tests/CompanionTests.swift), [DayTimelineTests](../Tests/DayTimelineTests.swift) и [CompanionNoticeTests](../Tests/CompanionNoticeTests.swift). Выполненные прогоны перечислены в [отчёте](../TEST_REPORT.md).
