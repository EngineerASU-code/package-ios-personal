# Допуск к выпуску

1. Идентифицировать рабочее дерево, версию и номер сборки. Проверить результаты для того же исходного кода в [отчёте](../TEST_REPORT.md).
2. Принять материалы по [реестру прав](ASSET_RIGHTS.md), утверждённую иконку и политику конфиденциальности.
3. Пройти испытания симулятора и физического устройства по [матрице](DEVICE_MATRIX.md), включая системную нагрузку и доставку.
4. На Mac собрать подписанный архив, проверить оба bundle и состав ресурсов, выполнить Validate App. Ответственные, сведения Apple и статус каждого пункта указаны в [чек-листе TestFlight](TESTFLIGHT_CHECKLIST.md).
5. Получить решение владельца по конкретному архиву и аудитории. Публикация требует отдельного разрешения.
