# Наблюдения по концептам

R01–R04 располагают героя и речевое облако в одной сцене. У Годжо светлые волосы читаются на холодном сине-фиолетовом фоне, у Тоджи сцена приглушена, у Женьши в палитре тёплые золотые детали.

R05–R09 используют фиолетовую дугу портала как обрамление силуэта Джин Ву. В малом размере сюжет читается по одному кадру. R10–R14 строят сцену Мао Мао на светлом фоне с тёплым светом, травами и деталями аптеки. В статичном режиме сохраняем характерный цвет и композицию.

Все JPEG служат референсами разработки. В target membership их нет. Для первого экрана выбран абстрактный системный символ и холодная палитра. Художественный образ и речевое облако требуют отдельной реализации.
