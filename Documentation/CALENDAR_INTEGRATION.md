# Системный календарь

Кнопка «Создать событие» открывает системный редактор EventKitUI. Только кнопка «Подключить календарь для чтения» может запросить полный доступ. Доступ к чужим событиям проверяется заново при обновлении. При отказе доступна ссылка на настройки iPhone. [Контроллер и интерфейс](../App/CalendarPanel.swift)

## Локальное расписание

Приложение запрашивает окно от текущего времени до той же локальной даты и времени через семь дней. Исключает отменённые и завершённые события, сортирует по началу и сохраняет до 100 уникальных вхождений. Ключ — SHA-256 от календарного идентификатора и времени начала. Перенос события меняет ключ, поэтому прежнее предупреждение можно отменить.

В общем снимке SQLite хранятся начало, конец, признак события на весь день, ключ, признак усечения и срок свежести. Названия скрыты по умолчанию. При явном разрешении заголовок ограничен 64 символами. Отдельная настройка приватности для виджета позволяет скрыть старый заголовок до повторного чтения базы. Устаревший снимок через 12 часов теряет статус актуального. [Модель и фильтрация](../Shared/CalendarSnapshot.swift)

Приложение обновляет расписание при переходе в активное состояние, изменении календаря или системного времени и по кнопке. Одинаковые данные при частых сигналах сохраняют прежний горизонт до 15 минут. Можно выбрать один из семи дней. События на несколько суток видны в каждом дне, с которым пересекаются. При усечении списка интерфейс сообщает об ограничении.

В одном из дневных слотов герой может упомянуть три и более оставшихся события или отсутствие записей до конца местного дня. Для обоих выводов требуется свежий снимок. Для пустого расписания он также должен быть полным. При сравнении свежих снимков герой различает изменение времени, явную пометку EventKit об отмене и исчезновение ранее видимой записи. Для одиночного события перенос можно сопоставить по дополнительному хешу календарного идентификатора. Для повторяющейся серии неоднозначное исчезновение получает нейтральную реплику. Реплики обходятся без заголовков событий. [Выбор кадров](../Shared/DayTimeline.swift)

Отключение чтения очищает локальный календарный снимок и отменяет будущие календарные предупреждения. Бюджет уже прошедших уведомлений сохраняет только ключи и даты. Исходные события остаются в системном календаре. При отзыве системного разрешения очистка происходит во время следующего доступного выполнения.

## Осталось подтвердить на iOS

На текущем кандидате требуется проверить системный редактор, отказ и отзыв доступа, перенос повторяющегося события, события на весь день, замену предупреждения и обновление уже размещённого виджета. Исторические прогоны привязаны к своим версиям приложения. [Матрица проверок](DEVICE_MATRIX.md)
