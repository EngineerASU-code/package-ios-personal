# Безопасность

Приложение и расширение виджета обмениваются состоянием через контейнер App Group `group.local.mycompanion`. Для новой БД на iOS задан класс защиты до первой разблокировки после загрузки. При ошибке доступа виджет показывает нейтральную подсказку. Проверка фактического доступа после перезагрузки и при повторной блокировке включена в [матрицу устройств](DEVICE_MATRIX.md).

Названия календарных событий попадают в представление виджета только при действующем разрешении в настройках приложения и экземпляра. До создания записей timeline удаляются заголовки локальных задач. Календарный снимок очищается при истечении срока свежести. Правила записи и поведение при повреждении описаны в [схеме хранения](STORAGE_SCHEMA.md).

Встроенные пакеты загружаются по идентификаторам шести героев. Валидатор сверяет состав каталога с манифестом и реестром прав, проверяет допустимые имена, сигнатуры PNG/JPEG, размеры и глубину JSON. При загрузке иллюстрации ImageIO проверяет определённый им тип и геометрию до создания уменьшенного изображения. Параметры приведены в [ADR о ресурсах](ADR/0003-resource-budgets.md).

Для выпуска архивный скрипт проверяет разрешения на персонажа и каждую иллюстрацию в составе продукта. Текущие личные ресурсы требуют подтверждения прав перед распространением. [Проверка архива](../Scripts/check_release_rights.py) · [Чек-лист TestFlight](TESTFLIGHT_CHECKLIST.md)
