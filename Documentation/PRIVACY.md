# Конфиденциальность «Моего Компаньона»

Приложение работает на устройстве без регистрации. Выбранный герой, настройки, история реплик, коллекция и локальные задачи сохраняются на iPhone. Приложение и его виджет используют общую область хранения. Встроенное приложение не отправляет эти данные разработчику.

Имя или прозвище можно указать в настройке «Как ко мне обращаться». Имя и выбранная форма обращения хранятся в настройках основного приложения и применяются при показе отдельных реплик на вкладке «Компаньон». В этом же разделе можно удалить имя. Сброс настроек очищает оба значения.

Календарь подключается по вашему выбору. Для показа расписания приложение запрашивает доступ к событиям и сохраняет ограниченный локальный снимок. По умолчанию названия скрыты. Их можно отдельно разрешить в приложении и скрыть для конкретного виджета. Отключение календаря очищает локальную копию при следующем выполнении приложения. Уже показанный кадр виджета обновляется по решению iOS.

Личные сообщения и напоминания доставляются через локальные уведомления iOS. Параметры экрана блокировки, предпросмотра и Focus задаются в системных настройках. Уведомления приложения можно отключить в настройках компаньона. Удаление виджета с домашнего экрана сохраняет расписание основного приложения.

В разделе «Локальные данные» можно отдельно очистить историю, коллекцию, задачи и снимок календаря. Системные события календаря при этом сохраняются. При выборе «Поделиться» открывается системное меню, в котором вы выбираете получателя.

Для публикации владелец должен утвердить редакцию, указать контакт для обращений и разместить политику по общедоступному адресу.

По команде «Сохранить отчёт в Файлы» диагностика формирует текст с версией приложения, версией iOS и статусом чтения общего хранилища. Место сохранения выбирает пользователь в системном диалоге.
