# Влияние на систему

| Наблюдение | Среда и результат |
| --- | --- |
| Предыдущий замер ядра | Windows x64, Swift 6.4.3, Debug, прогретые пакеты, рабочая копия на базе `e2ce9dd`. В 120 выборках рассчитано 1560 кадров. p95 реакции — 0,600 мс, серии кадров — 1,032 мс. |
| Текущая реализация загрузки изображений | Исходники на базе `83723ac` используют ImageIO. Сравнение пиковой и устойчивой памяти до и после изменения на iOS ожидает замера. |
| Физический iPhone | NOT_MEASURED. Открыты холодный и прогретый запуск, задержка AppIntent до отображения, CPU/GPU, память, температура, энергия, пропуски кадров и вытеснение процессов. |
| Эксплуатация 24/72 часа | NOT_MEASURED. Для фоновой доставки, расхода заряда и поведения соседних приложений нужны сопоставимые прогоны A–E на одном устройстве. |

Условия переносимого прогона записаны в [отчёте испытаний](../TEST_REPORT.md). Для физических результатов предусмотрены исходные показания, модель устройства, версия iOS, SHA, длительность наблюдения и диапазон разброса. Порядок сравнения и перечень условий приведены в [матрице устройств](DEVICE_MATRIX.md).
