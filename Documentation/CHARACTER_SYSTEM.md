# Система персонажей

Персонажи доступны офлайн в приложении и расширении WidgetKit. Путь пакета строится из стабильного значения `Hero.rawValue` в `Shared/Characters`. Этот же ID связывает историю взаимодействий, выбранную реплику и настройки экземпляра виджета с героем.

| Герой | ID пакета | Базовое настроение |
|---|---|---|
| Сатору Годжо | `satoru_gojo` | playful |
| Тоджи Фушигуро | `toji_fushiguro` | focused |
| Женьши | `jinshi` | curious |
| Сон Джин Ву | `sung_jinwoo` | focused |
| Рёмен Сукуна | `ryomen_sukuna` | confident |
| Мао Мао | `maomao` | curious |

## Что входит в пакет

| Файл | Назначение |
|---|---|
| `manifest.json` | ID, имя, версия схемы 1, локаль, перечень файлов и форм. Загрузчик проверяет версию и совпадение ID с каталогом. |
| `personality.json`, `emotions.json` | Краткое описание речи, уровень intensity, базовое настроение и настроение восстановления для запасной реакции. |
| `behaviors.json` | Записи с ID, подписью действия и переходом from → to. Загрузчик также понимает условия, каналы, триггеры, вес, приоритет и cooldown в секундах. |
| `dialogue.ru.json` | 150 реплик и их связи с действиями. Подробнее в [схеме реплик](DIALOGUE_SCHEMA.md). |
| `easter_eggs.json` | Пять карточек с уникальным ID, названием, ссылкой lineID на редкую реплику и assetID системного символа. |
| `theme.json`, `animations.json` | Цвет и символ темы. Дескриптор перехода содержит ID нативного эффекта, поверхности, исходную и конечную позы, длительность, ресурсы, режим движения и статичный запасной кадр. |
| `rights.json` | Происхождение и статус распространения иллюстраций. Условия выпуска приведены в [реестре прав](ASSET_RIGHTS.md). |

## Путь события

1. Приложение или виджет передаёт в `Companion.handle` ID события, источник, тип и время. Ядро отбрасывает повторные, будущие и устаревшие события и выбирает приоритетный ответ.
2. Активный пакет даёт допустимые для этого контекста действия и реплики. Ядро выбирает ответ, обновляет настроение, параметры героя и историю его фактических взаимодействий. Энергия, любопытство и раздражение восстанавливаются по прошедшему времени при следующем обращении.
3. `Store.update` записывает результат в транзакции SQLite. Виджет с фиксированным героем обновляет его историю, сохраняя выбор основного героя приложения.
4. `DayTimeline` вычисляет кадры из снимка и локального времени. Фактический утренний контакт расходует приветствие. Чтение пассивного кадра сохраняет возможность получить его позднее.

В обычном режиме редкая реакция может открыть карточку. Общий интервал между открытиями составляет шесть часов. В снимок записываются ID находки, время и символ. Старые открытия без символа получают его из пакета. Очистка коллекции, истории реплик и игровой активности выполняется раздельно. Приложение сохраняет задачи и календарный снимок при этих операциях.

За реализацию отвечают [ядро](../Shared/Companion.swift), [timeline](../Shared/DayTimeline.swift) и [рендерер](../Shared/Scene.swift). Изменения числа героев и состава файлов проверяет [валидатор пакетов](../Scripts/validate_content.py). Результаты сборки, симулятора и устройства фиксируются отдельно в [отчёте](../TEST_REPORT.md).
