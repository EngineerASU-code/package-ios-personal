# Этап 03. Ядро компаньона

Доведи до приёмки связанный цикл «событие → поведение и эмоция → реплика → сохранённое состояние» для всех шести героев.

## Исходные материалы

Работай в репозитории «Мой Компаньон». Прочитай AGENTS.md, соответствующие разделы Documentation/PRODUCT_SPEC.md и относящиеся к этапу записи TEST_REPORT.md. Ориентиры для этого задания — §§ 6, 9–11, 15–17, 22, 26.1–26.2; Shared/Companion.swift, Shared/DayTimeline.swift, Shared/CompanionNoticePlan.swift, Tests, JSON пакетов героев.

До правок зафиксируй ветку, HEAD, staged, unstaged и untracked. Сверь старые результаты с текущим деревом, включая локальные правки других агентов. Если критерий уже подтверждён для этого состояния, приведи доказательство. Если обнаружен пробел, выполни работу и проверь её.

## Задачи и проверки

1. Начни с незакоммиченного кода. В обследованном дереве уже есть чтение emotions.json и behaviors.json, фильтр канала уведомлений, тесты истории и времени суток. Проследи каждый путь до реального потребителя. Подтверди, какие пробелы ещё существуют.

2. Для каждого героя проверь базовое настроение, индивидуальную реакцию, пределы параметров и восстановление по прошедшему времени. Проведи событие через разрешённый переход поведения с учётом условий, приоритета, веса и cooldown. Обработай невозможный переход и отсутствие ресурса безопасным состоянием.

3. Сверь триггеры с §11.3. Передавай источник, ID и время. Повторное и просроченное событие обработай идемпотентно. При конкуренции выдай один визуальный ответ по таблице приоритетов. Пауза декора сохраняет задачи пользователя.

4. Проверь выбор реплики на всех поддерживаемых поверхностях: канал, контекст, настроение, интенсивность, обязательные переменные, вес, история и разрешённый fallback. Проверь изоляцию истории и открытий героев после переключения и перезапуска.

5. Проверь утреннее приветствие один раз за локальный день, границы ночи, DST, смену зоны, перевод часов назад и долгое отсутствие. Timeline должен быть ограниченным, отсортированным и без записи при чтении. Проверь Safe/Eco/Pause при входе и выходе.

6. Добавь недостающие детерминированные тесты с управляемыми часами и RNG. Включи сквозной тест конфигурация героя → событие → переход → реплика → сохранение → восстановление и тест совместимости старого снимка.

У всех шести героев в набор дополнительно попала `morning`.

2. По §§ 10–11 и 15–16 спецификации установи, когда допустима утренняя реплика и какое событие расходует однократное приветствие. Проследи путь от локального времени, триггера и полей записи в пакете героя до выбора в `DayTimeline.display`. Установи источник расхождения в реализации, данных или ожидании теста. 3. Закрепи правило детерминированными примерами для утреннего и дневного кадра и первого фактического взаимодействия. 4. После исправления повтори целевой тест и полный `swift test` без фильтра. Запусти валидатор контента и все предусмотренные проектом интеграционные и UI-тесты в доступной Apple-среде. ## Очерёдность и границы работы

**Старт.** В первой волне вместе с этапами 0 и 4. ТЗ выполняет текущий координатор или назначенный им исполнитель. При отключении прежнего чата координатор принимает этап и продолжает с текущего рабочего дерева, сохраняя незавершённые изменения.

Твоя зона — Shared/Companion.swift, Shared/DayTimeline.swift и тесты ядра, включая Tests/DayTimelineTests.swift. По сбою morning проверь логику на зафиксированной версии данных: до воспроизведения агент 4 только вычитывает пакеты. Если причина в JSON, передай точный ID, поле и ожидаемое условие агенту 4, затем повтори тесты на согласованном наборе. Изменения контракта загрузчика передай 4 до редактирования пакетов.

В параллельной волне результаты отправляй в своём ответе. Общий TEST_REPORT.md сводит агент 9. Перед записью сравни текущий diff с исходным. Уже изменённый другим чатом файл остаётся у его действующего владельца до явной передачи. В передаче укажи путь, состояние кода, изменённый контракт и результат проверки. При пересечении передай запрос владельцу и продолжи независимые пункты. Полное расписание — в [общем промпте](STAGE_CLOSURE_PROMPT.md).
