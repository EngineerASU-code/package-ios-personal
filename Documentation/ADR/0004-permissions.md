# 0004. Разрешения по действию пользователя

**Решение.** На первом запуске пользователь может выбрать героя и использовать приложение без системного запроса. Разрешение запрашивается в момент включения конкретной функции.

| Действие | Разрешение и данные |
|---|---|
| Создать локальную задачу | Данные сохраняются в App Group. EventKit для локальных задач не используется. |
| Создать календарное событие | Приложение показывает системный редактор EventKitUI после нажатия. Сохранение подтверждает пользователь. |
| Читать системный календарь | При подключении приложение запрашивает полный доступ EventKit на iOS 17+. Русский текст системного запроса задан в `NSCalendarsFullAccessUsageDescription`: «Показывать ближайшие события в расписании и виджете по вашему выбору.» Названия событий требуют отдельного включения в приложении. |
| Получать уведомления | Запрос UserNotifications следует за включением соответствующего вида либо явной постановкой уведомления. Задачу можно сохранить при отказе. Включённый Focus и системные настройки доставки продолжают действовать. |
| Показать виджет | Расширение читает общий локальный снимок и опубликованный режим приватности. Доступ к EventKit запрашивает основное приложение. |

Путь записи через системный редактор и локальная модель задач позволяют обойтись без запросов прямого доступа на запись в календарь и чтения системных напоминаний. При появлении любой из этих интеграций потребуется отдельное решение с описанием её назначения и поведения при отзыве доступа. **Осталось подтвердить.** На iPhone проверить русский текст системного запроса, отказ, последующий отзыв в настройках, сохранение локальной задачи и исчезновение старого календарного содержимого из виджета при следующем обновлении.
