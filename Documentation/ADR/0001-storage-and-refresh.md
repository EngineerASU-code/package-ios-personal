# Общий снимок и обновление виджета

Храним версию формата и компактный JSON в одной строке SQLite. BEGIN IMMEDIATE сериализует чтение и изменение между процессами. При ошибке транзакция откатывается. Неизвестная версия останавливает запись. Для локальных интеграционных тестов можно передать отдельный URL базы.

Medium-виджет читает снимок один раз через SQLite в режиме read-only и рассчитывает до 12 часов локальных сцен. В Normal используются часовые границы, в Eco — преимущественно двухчасовые с переходом на рассвет в 05:00. Границы ближе пяти минут к начальному кадру сдвигаются. Следующий запрос планируется на конец горизонта. Safe, Pause и ошибка чтения дают один кадр до внешнего обновления. После сохранения в приложении WidgetCenter получает запрос на обновление. Интерактивность виджета использует AppIntent. Фактическую перерисовку после нажатия нужно подтвердить в WidgetKit на iOS. Safe и Pause показывают статичную сцену.
