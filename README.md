# Мой Компаньон

Первый вертикальный прототип для iPhone с iOS 17. Откройте MyCompanion.xcodeproj в Xcode и выберите схему MyCompanion для симулятора iPhone. В проекте объявлены три размера домашнего виджета и три accessory-формата. Конфигурация поддерживает основного и фиксированного героя. Для общей SQLite-базы оба процесса используют группу group.local.mycompanion. Идентификаторы локальные, команда подписи не задана.

Проверьте смену реплики на главном экране и в виджете, затем переключите безопасный режим. Кнопка напоминания запрашивает разрешение и планирует одно уведомление через минуту. Изолированные тесты модели запускаются командой `swift test` из корня.
