# Мой Компаньон

Локальный компаньон для iPhone с iOS 17 и новее. В главной сцене можно выбрать одного из шести героев и получить его реплику. Рядом находятся календарь и напоминания. Откройте MyCompanion.xcodeproj в Xcode и выберите схему MyCompanion для симулятора iPhone. В проекте объявлены три размера домашнего виджета и три accessory-формата. Конфигурация поддерживает основного и фиксированного героя. Для общей SQLite-базы оба процесса используют группу group.local.mycompanion. Расширение Device Activity Monitor обрабатывает добровольный дневной порог выбранного приложения. При выборе города WeatherKit может менять настроение героя. Для работы этих интеграций на iPhone нужны соответствующие возможности Apple Developer и подпись.

Проверьте смену реплики на главном экране и в виджете, затем переключите безопасный режим. В «Настройки → Диагностика» можно по явному действию запланировать проверочное уведомление через минуту, отменить его или сохранить локальный отчёт. Изолированные тесты модели запускаются командой `swift test` из корня.
